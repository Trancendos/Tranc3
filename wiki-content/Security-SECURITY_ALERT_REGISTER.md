# Security Alert Register

> **This page is a pointer. The register itself is
> [`SECURITY_ALERT_REGISTER.md`](https://github.com/Trancendos/Tranc3/blob/main/SECURITY_ALERT_REGISTER.md)
> in the repository.**

## Why this page no longer holds the register

Until 2026-09-04 this page held a second, separate copy of the security alert register.
The canonical register at the repository root is actively monitored by `scripts/security_score.py`
and reviewed during PRs. Having two copies led to divergent truth and missed tracking.

## What belongs here instead

Wiki pages are the **administrative** view: orientation, navigation, and
narrative. The actual alert triage and tracking belongs in the repository
file so that it can be audited and linked in PRs.
