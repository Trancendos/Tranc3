# TRANC3 API Reference

> **This page is a pointer. The reference itself is
> [`docs/API_REFERENCE.md`](https://github.com/Trancendos/Tranc3/blob/main/docs/API_REFERENCE.md)
> in the repository.**

## Why this page no longer holds the reference

Until 2026-09-04 this page held a second, shorter API reference: 238 lines
documenting 9 endpoints, against the repository's 750 lines documenting 47.
Every endpoint here appeared there, so nothing was lost by pointing at it —
but a reader landing here would have seen a fifth of the API and had no way
to know it.

A reference that ships beside the code is the one that gets updated when a
route changes. A copy in the wiki is updated when somebody remembers.

## What belongs here instead

Wiki pages are the **administrative** view: orientation, navigation, and
narrative. Endpoint-level truth belongs next to the endpoints.
