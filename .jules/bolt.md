## 2023-10-13 - Python 3.12 `math.sumprod` Performance Optimization
**Learning:** In Python 3.12+, `math.sumprod(a, b)` is executed entirely in C and is significantly faster than both a combined pure Python `zip()` loop (by ~3x) and separate C-optimized `map(operator.mul, a, b)` passes (by ~3x) when computing dot products and norms for metrics like Cosine Similarity.
**Action:** When computing dot products or sum-of-squares in pure Python fallback paths, always use a module-level feature flag `_HAS_SUMPROD = hasattr(math, 'sumprod')` to detect Python 3.12+ and prefer `math.sumprod`. Add `# type: ignore[attr-defined]` to satisfy older versions of mypy.
