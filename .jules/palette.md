## 2024-10-16 - Inline Text Edit Accessibility
**Learning:** Inline text inputs masquerading as headings or generic buttons (like clicking on a title to edit it) often lack `aria-label` or programmatic association with preceding text. Without visual labels or standard `htmlFor` pairings, screen readers cannot identify the purpose of the input field, leading to severe accessibility barriers for keyboard/audio-only users attempting to edit entity names.
**Action:** When implementing inline editing for headings (like the `nameEdit` pattern in `DigitalGridPage`), always add an explicit `aria-label` to the `<input>` element that clearly describes its purpose (e.g., `aria-label="Workflow name"`). In complex properties panels, ensure all `<label>` elements are strictly bound to their corresponding `<input>` using the `htmlFor` and `id` attributes.
